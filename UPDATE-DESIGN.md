# MunchQuest — Retro New York update

New York wording, five boroughs, borough filtering/grouping and original demo categories have been restored. Your supplied photos remain available as illustrative cuisine images. Added paper texture, diner borders, offset lettering, framed cards, and a checker detail.

## Fresh extraction (recommended)
Extract the ZIP. Open restaurant-final in VS Code. Run npm.cmd install and wait for completion, then npm.cmd run demo. Open http://localhost:3000. Demo changes reset on restart.

## Updating an installed folder
Stop with Ctrl+C. Replace public, lib, server.js, and test from this download. Keep your existing node_modules and database configuration. Run npm.cmd run demo and refresh with Ctrl+F5. If Express is missing, run npm.cmd install first.

The actual MongoDB database was not modified. Demo records are fictional; the original dataset still needs to be connected. Live MongoDB/Atlas verification and the professor's intended ranking formula remain pending.

Keep original source/credit information for your supplied photographs.
